# Growatt Cloud

Home-Assistant-Add-on: Daten aus der **Growatt Cloud** für **Noah, Nexa und Wechselrichter** → MQTT.

## Installation

1. Einstellungen → Apps → ⋮ → Repositories  
2. `https://github.com/5snowflake5/growatt-cloud`  
3. **Growatt Cloud** installieren  

Token: [openapi.growatt.com](https://openapi.growatt.com) → Account → API Token

## Release

Siehe [RELEASE.md](RELEASE.md): Version in `config.yaml` **nicht** von Hand ändern → Actions **Release add-on** → dann in HA updaten.
